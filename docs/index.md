# Sistema de Reconhecimento Facial para Controle de Presença

Bem-vindo à documentação oficial do Sistema de Reconhecimento Facial para controle de presença acadêmica.

##  Visão Geral

Este sistema utiliza tecnologia de reconhecimento facial para automatizar o controle de presença em ambientes educacionais, oferecendo uma solução moderna, eficiente e segura.

##  Principais Funcionalidades

- **Reconhecimento Facial Híbrido**: Combina `face_recognition` e `DeepFace` para maior precisão
- **Gestão Completa**: Alunos, professores e turmas
- **Validação de Presença**: Sistema de verificação por professores
- **Interface Intuitiva**: Frontend moderno e responsivo
- **API RESTful**: Backend robusto com FastAPI
- **Pré-processamento de Imagens**: Otimização automática para melhor desempenho
